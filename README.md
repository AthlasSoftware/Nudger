# CursorBuddyAI

A playful macOS menubar app that puts an AI-powered desk buddy on your screen. It watches what you're doing (without screenshots!) and occasionally suggests helpful Swedish tips and recommendations using ChatGPT.

## What It Does

- **Buddy Cursor**: A tiny cursor-shaped companion that sits on your desktop at a fixed position
- **Smart Suggestions**: Periodically shows speech bubbles with Swedish text generated by ChatGPT based on your current app context
- **Privacy-First**: Only sends lightweight metadata (app name, bundle ID, window title) — **no screenshots or content**
- **Minimal & Playful**: Clean UI, low CPU usage, customizable frequency
- **Quick Actions**: Accept suggestions with ✓ to trigger actions (like opening URLs), or dismiss with ✕

## Setup

### 1. OpenAI API Key

CursorBuddyAI requires an OpenAI API key to function. Set it as an environment variable:

```bash
export OPENAI_API_KEY="sk-your-key-here"
```

Make it permanent by adding to your shell profile (`~/.zshrc` or `~/.bash_profile`):

```bash
echo 'export OPENAI_API_KEY="sk-your-key-here"' >> ~/.zshrc
```

Then restart the app or launch it from a shell that has the environment variable set.

### 2. Optional Configuration

You can customize the OpenAI settings via environment variables:

```bash
# Use a different model (default: gpt-4o-mini)
export OPENAI_MODEL="gpt-4o"

# Use a custom API endpoint (default: https://api.openai.com/v1)
export OPENAI_BASE="https://your-custom-endpoint.com/v1"
```

### 3. Launch the App

Build and run from Xcode, or build a release version and add to your Login Items.

## Usage

### Menu Bar Controls

Click the CursorBuddyAI icon in your menu bar to access:

- **Aktiv**: Toggle the buddy on/off
- **Frekvens**: Slider to control how often suggestions appear (0% = never, 100% = very frequently)
- **Lekfull ton**: Toggle between playful and plain Swedish tone
- **Be om Hjälpmedelstillgång (AX)**: Request Accessibility permissions (optional, improves window title detection)
- **Debug**:
  - **Visa bubbla nu**: Manually trigger a suggestion (⌘⇧T)
  - **Återställ position**: Reset buddy to default bottom-right position

### Repositioning the Buddy

1. Hold down the **⌘ (Command)** key
2. Click and drag the buddy cursor to a new position
3. Release ⌘ to save the position

The buddy will remember its position between app launches.

### Interacting with Suggestions

When a speech bubble appears:

- **✓ (Checkmark)**: Accept the suggestion and trigger its action
- **✕ (X)**: Dismiss the bubble
- Bubbles auto-hide after ~6 seconds if you don't interact

## Privacy & Data

CursorBuddyAI is designed with privacy in mind:

- **No screen capture**: The app never takes screenshots or captures screen content
- **Minimal context**: Only sends app name, bundle ID, and window title (max 120 characters) to OpenAI
- **No persistent logs**: Your activity is not stored or analyzed
- **Optional AX**: The app works without Accessibility permissions; enabling AX only improves window title detection

## Requirements

- **macOS 14.0+** (Sonoma or later)
- **OpenAI API key** (required for suggestions)
- **Swift 5.9+** / Xcode 15+ (for building)

## Architecture

The app is built with **Swift, SwiftUI, and AppKit**:

- `App/CursorBuddyAIApp.swift`: Main app entry with MenuBarExtra
- `Buddy/`: Buddy cursor panel and controller
- `UI/`: SwiftUI views for buddy and bubble
- `Suggest/`: Suggestion scheduling with jittered timers and cooldowns
- `Services/`: Context service (monitors active app/window)
- `LLM/`: OpenAI API client and data schemas
- `Automation/`: Routes actions (URL opening, future AppleScript integrations)
- `Settings/`: UserDefaults-backed settings store
- `Permissions/`: Accessibility permission helpers
- `Logging/`: Centralized logging with os.Logger

## Troubleshooting

### "Ställ in OPENAI_API_KEY för att aktivera mig"

The app couldn't find your API key. Make sure you've set the `OPENAI_API_KEY` environment variable and launched the app from a shell or environment that has access to it.

### Suggestions aren't appearing

- Check that **Aktiv** is enabled in the menu bar
- Increase the **Frekvens** slider
- Check Console.app for any errors from CursorBuddyAI
- Verify your OpenAI API key is valid and has credits

### Window titles are empty

The app needs **Accessibility permissions** to read window titles. Click "Be om Hjälpmedelstillgång (AX)" in the menu and grant permission in System Settings.
